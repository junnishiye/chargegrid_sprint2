## Objetivo

Desenvolver uma solução integrada para gerenciamento inteligente de recarga comercial, envolvendo controle de demanda, prioridade energética, tarifação dinâmica, análise de dados, simulação física e chatbot de suporte.

## Estrutura do Repositório

- arquitetura_circuito: circuito lógico, expressão booleana, tabela verdade e relatório.
- computer_science: algoritmo Python e simulação Arduino.
- sistema_recarga: sistema principal com múltiplas sessões, menu, tarifação e integração simulada.
- modelagem_linear: base de dados, gráficos, estatística descritiva e relatório.
- modelagem_matematica: resolução da atividade de máximo e mínimo.
- chatbot_goodwe: chatbot com contexto GoodWe, testes e documentação.
- pensamento_computacional: links e materiais da prova de conceito.
- energias_renovaveis: prova de conceito e justificativa sustentável.
- videos: links dos vídeos.
- entregas_txt: arquivos finais em .txt para as matérias que pedem apenas links.
